# smelt — Handover 2026-09-13

## Project
Universal file ingestion MCP server for the shadowlabs Claude ecosystem.
Raw files in → lean Markdown out. Saves tokens across all Claude surfaces.
Registered at `~/.claude/.mcp.json`. Production target: Acer Aspire (ASR).

---

## Tasks Completed This Session

### P0 — Foundation (DONE, committed 2f2275e)
- stdio MCP server via FastMCP
- markitdown conversion: PDF, DOCX, PPTX, XLSX, HTML, CSV, ZIP, YouTube URLs
- 3-tier auto-selection: direct (<20k) / cache (20k–100k) / chunk (>100k)
- Tools: `smelt_file`, `smelt_chunk`, `smelt_status`
- Image passthrough (PNG/JPG flagged as native)
- Registered in `~/.claude/.mcp.json`

### P1 — OCR + Persistence (DONE, committed d13fa8d + b66a285)
- SQLite store at `~/smelt-store/chunks.db` — survives restarts
- SHA-256 dedup: same file = instant cache hit, no re-processing
- PyMuPDF image-PDF auto-detect: majority-vote (>50% empty pages → OCR)
- Tesseract OCR: page-by-page at 300 dpi
- `quality` param: `"fast"` (markitdown default) / `"accurate"` (marker-pdf, optional)
- `doc_type` field: ingot-ready labels (e.g. `"bank_statement"`)
- 6-month TTL with `smelt_expire()` → moves stale files to `~/smelt-store/clearance/`
- `smelt_status()`: lists store with age + TTL countdown

### Naming (this session)
- Renamed project `mcp-ingestor` → `smelt` (forge metaphor, pairs with future `ingot`)
- All tools renamed: `ingest_*` → `smelt_*`
- Memory + MCP registration updated

### OCR bug fix (committed b66a285)
- Old: `_is_image_pdf()` returned False on first page with any text
- Fix: majority-vote — ResearchGate-wrapped scans (1 text cover + N image pages) now correctly routed to Tesseract
- Tested: 756 chars (wrong) → 28,773 chars (correct) on 1990 academic paper

## Current State

### Working ✅
- `smelt_file(path)` — converts any text PDF, DOCX, XLSX, HTML, CSV, YouTube URL
- `smelt_file(path)` — auto-detects image PDFs, runs Tesseract OCR
- SHA-256 dedup — cache hits in <50ms vs 0.3–13s for fresh converts
- `smelt_chunk(file_id, N)` — fetches 40k-char chunks of large files
- `smelt_status()` — lists store with TTL info
- `smelt_expire()` — moves 6-month-old entries to clearance dir
